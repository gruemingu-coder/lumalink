# App icons required before building

Tauri needs real icon files at the paths referenced from `tauri.conf.json`
(`32x32.png`, `128x128.png`, `128x128@2x.png`, `icon.icns`, `icon.ico`).
Binary image files can't be generated by the coding agent, so generate them
yourself from a single square source image (ideally 1024x1024 PNG):

```powershell
npm install
npx tauri icon path\to\lumalink-logo-1024.png
```

This writes all required formats/sizes directly into this `icons/` folder.
Until you do this, `npm run tauri:dev` / `npm run tauri:build` will fail
with a missing-icon error.
